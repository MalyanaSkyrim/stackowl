## How the scripts behave

The setup checks and steps come from [setupwise](https://www.npmjs.com/package/setupwise), configured in `setupwise.config.ts`. Every one is built the same way, so you can run any of them without fear:

- **Dry run first.** Without `--apply` a command only prints what it would change, with a `+` in front.
- **Safe to run again.** A step skips what already exists, so re-running it after a failure picks up where it stopped.
- **Values are never printed.** Secrets are compared, not shown.
- **One way to read keys.** Everything reads the root `.env`.

## What stays by hand, on purpose

Some steps need a person: paying for the Apple Developer Program, the agreements and tax forms in App Store Connect, App Privacy answers, and writing database migrations. The pages mark these steps.
