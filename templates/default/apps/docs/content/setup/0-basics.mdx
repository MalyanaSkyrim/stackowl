## What to decide

| Value                | Example                                                       | Used by                                                                        |
| -------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| App name             | Starter App                                                   | The App Store, the home screen, emails. Kept in `packages/common/src/brand.ts` |
| Bundle id            | `com.example.starterapp`                                       | Apple, signing, Sign in with Apple                                              |
| Website              | `www.example.com`                                          | Privacy, terms and support links in the app and the store                      |
| API and inbox domain | `example.com` (`api.`, `api-staging.`, `support@`)           | Cloud Run, Resend                                                              |
| Cloud region         | `europe-west1`                                                | Every Google Cloud service                                                     |
| Environments         | `staging` (branch `main`), `production` (branch `production`) | Deploys, secrets, databases                                                    |

<Steps>
<Step>

### Check the name is free on the App Store

Search the App Store, and App Store Connect when you create the app. Apple refuses a name another developer already uses, and a name too close to one can lead to a 4.3 "spam" rejection.

</Step>
<Step>

### Pick the bundle id

Reverse domain style, lowercase, never changed after the first upload. Apple ties the app, its purchases and its Sign in with Apple users to it. `setupwise create` asked for it and wrote it everywhere it's used.

</Step>
<Step>

### Buy the domain

Put its DNS with a provider you like (Cloudflare is free). It holds the records for the website, the API and the email domain; later phases add records to it.

</Step>
<Step>

### Write the name in one place

`brand.displayName` in `packages/common/src/brand.ts`. The app, the website and the emails read it from there; never type the name in code.

</Step>
</Steps>

<Callout type="success" title="Check it">
  You can say the app's name, bundle id, website, API domain and region without
  looking them up.
</Callout>
