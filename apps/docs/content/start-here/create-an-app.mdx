---
title: Create an app from nothing
description: One line on a new computer gives you a web app, an API, an iPhone app, docs and infrastructure, running locally.
---

The starter is a full product skeleton: a website, an API with accounts, an iPhone app, a docs site, the cloud infrastructure and the CI that deploys them. `setupwise create` copies it, gives every name and id your app's own, installs it and starts the local database.

## On a computer with nothing installed

<Tabs items={['macOS', 'Linux', 'Windows']}>
  <Tab value="macOS">

```sh
curl -fsSL https://raw.githubusercontent.com/MalyanaSkyrim/setupwise/main/install/install.sh | bash -s my-app
```

It installs what is missing (the Xcode command line tools, Homebrew, Node.js 24, pnpm and Docker Desktop), says each one before it installs it, then runs `setupwise create my-app`. Add `--cloud` to also install the GitHub CLI, the Google Cloud CLI and OpenTofu.

  </Tab>
  <Tab value="Linux">

```sh
curl -fsSL https://raw.githubusercontent.com/MalyanaSkyrim/setupwise/main/install/install.sh | bash -s my-app
```

It installs Node.js 24 with fnm and pnpm with corepack. Install git and Docker with your package manager first.

  </Tab>
  <Tab value="Windows">

```powershell
irm https://raw.githubusercontent.com/MalyanaSkyrim/setupwise/main/install/install.ps1 | iex
```

It installs Git, Node.js 24, pnpm and Docker Desktop with winget. The iPhone app needs a Mac to build; everything else works on Windows.

  </Tab>
</Tabs>

```sh
npx setupwise create my-app
```

Then:

```sh
cd habit-tracker
pnpm dev                                  # API :4000, website :3003, Metro
pnpm --filter=@habit-tracker/mobile ios   # the iPhone app (needs Xcode)
pnpm docs                                 # the project's own docs: every setup step
```

Sign in with `demo@example.com` / `password123`.

## What you get

| Folder             | What                                                                   |
| ------------------ | ---------------------------------------------------------------------- |
| `apps/api`         | Fastify and tRPC: email, Apple and Google sign-in, and a notes example |
| `apps/mobile`      | Expo iPhone app: sign-in, notes, settings, English, French and Arabic  |
| `apps/web`         | Next.js website: landing page, privacy, terms, support                 |
| `apps/docs`        | The project's docs (Fumadocs): every setup step, in order              |
| `apps/workshop`    | Storybook for the UI kit                                               |
| `packages/*`       | Shared UI kit, design tokens, schemas, database (Prisma)               |
| `infra/`           | OpenTofu for Google Cloud: Cloud Run, Secret Manager, deploy access    |
| `.github/`         | CI, staging and production deploys, TestFlight builds                  |
| `setupwise.config.ts` | What `pnpm doctor` checks and `setup` sets up                       |

The **notes** feature goes through every layer, from the Prisma model to the API module to the app's screens. Copy it for your first real feature, then delete it.

## From a template of your own

```sh
npx setupwise create my-app --from github:acme/starter        # a GitHub repository
npx setupwise create my-app --from github:acme/mono/starter#v2 # a folder, at a tag
npx setupwise create my-app --from ../my-starter              # a local folder
```

A template says which words to replace in a `setupwise.template.json`: [Templates](../reference/templates.mdx).
