---
title: stackowl init
description: Writes stackowl.config.ts from a few questions.
---

```sh
stackowl init [--yes] [--force]
```

Asks for the project's name, its deploy environments and the services to check (GitHub, Google Cloud), then:

- writes `stackowl.config.ts` in the current folder, with every section commented;
- adds `.env`, `.env.*` and `!.env.example` to `.gitignore` if they aren't there.

| Option    | Effect                                                   |
| --------- | -------------------------------------------------------- |
| `--yes`   | Skip the questions: the folder's name, `staging` and `production`, GitHub and Google Cloud |
| `--force` | Overwrite an existing config in this folder              |

The config imports `defineConfig` from `stackowl` for types. It works under `npx` too: StackOwl resolves that import to itself when it loads the file.
