---
title: Troubleshooting
description: What a line in the report means, and what to do about it.
---

<Accordions>
<Accordion title="No stackowl.config found: checking the basics only">

There is no config in this folder or any folder above it. Run `npx stackowl init` at the project's root, or pass `--config path/to/stackowl.config.ts`.

</Accordion>
<Accordion title="gh is not logged in: GitHub skipped">

Run `gh auth login`. In CI, set `GH_TOKEN`.

</Accordion>
<Accordion title="this folder has no GitHub remote gh can read: GitHub skipped">

The repository isn't on GitHub yet, or `gh` can't see it. Check with `gh repo view`. With several remotes, run `gh repo set-default`.

</Accordion>
<Accordion title="can't read the production environment's secrets: does it exist?">

Create the environment in GitHub → Settings → Environments, or check that your token has admin access to the repository.

</Accordion>
<Accordion title="GCP_PROJECT_ID is not set: Google Cloud skipped">

Add the project id to the env file, or set `gcp.project` in the config.

</Accordion>
<Accordion title="… has no value (or no access)">

Either the secret was never given a value, or your account can't read it. Check with `gcloud secrets versions list <id>`, then run `stackowl secrets set <environment> --apply`.

</Accordion>
<Accordion title="… still holds the placeholder">

Your infrastructure code created the secret with the placeholder value. Add the real value to `.env.<environment>` and run `stackowl secrets set <environment> --apply`.

</Accordion>
<Accordion title="Unknown or disabled module">

The module's section isn't in the config, so it doesn't run. `stackowl modules` lists what this project uses.

</Accordion>
</Accordions>
