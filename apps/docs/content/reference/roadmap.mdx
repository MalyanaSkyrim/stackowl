title: Roadmap
description: Where StackOwl is going after the first release.
---

The first release checks and sets up tools, env keys, GitHub and Google Cloud secrets. Next, in order:

Done: `stackowl create`, the starter template and the installers.

1. **More modules.** Apple (App IDs, capabilities, signing), App Store products and listing, RevenueCat, Cloudflare R2 storage, Resend domains, database migrations applied.
2. **AWS and other clouds**, behind the same `secrets set` command: AWS Secrets Manager, Azure Key Vault, Doppler.
3. **`stackowl docs`**: fills a setup guide like [this one](../guides/project-setup.mdx) with the project's own names, ids and domains.
4. **Modules as packages**: `stackowl-module-stripe`, loaded by name from the config.

## What stays project-specific

The project owns its content: the names, the values, the store texts, the business rules. StackOwl owns the format and the commands.
