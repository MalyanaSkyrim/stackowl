**SetupWise** starts a full app from nothing, and keeps everything it needs outside its code in check.

- `setupwise create my-app` gives you a website, an API with accounts, an iPhone app, a docs site, cloud infrastructure and CI, renamed for your app and running locally. On a new computer, one line installs the tools first: [Create an app from nothing](start-here/create-an-app.mdx).
- `setupwise doctor` checks what a project needs outside its code: tools on each machine, keys in the env file, GitHub variables and secrets, cloud secret values. `setup` sets up what it can. All of it is written down in one typed file, `setupwise.config.ts`.

## The rules every command follows

- **Dry run first.** A command that changes something only prints what it would do (`+ … (dry run)`) until you add `--apply`.
- **Safe to run again.** What is already right is skipped, so re-running after a failure picks up where it stopped.
- **Values are never printed.** Secrets are compared, not shown. Errors name the variable, never its content.
- **One place for keys.** Everything reads the same env file, and the process environment wins over it.
- **CI friendly.** `doctor` exits with 1 when something must be fixed, and `--json` gives a machine-readable report.
