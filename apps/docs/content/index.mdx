A project needs more than its code to run: tools on each developer's machine, keys in an env file, variables and secrets on GitHub, and secret values in the cloud. These are set up by hand, once, and then forgotten until something breaks. **setupwise** writes down what the project needs in one typed file, checks it with one command and sets up what it can.

## The rules every command follows

- **Dry run first.** A command that changes something only prints what it would do (`+ … (dry run)`) until you add `--apply`.
- **Safe to run again.** What is already right is skipped, so re-running after a failure picks up where it stopped.
- **Values are never printed.** Secrets are compared, not shown. Errors name the variable, never its content.
- **One place for keys.** Everything reads the same env file, and the process environment wins over it.
- **CI friendly.** `doctor` exits with 1 when something must be fixed, and `--json` gives a machine-readable report.
