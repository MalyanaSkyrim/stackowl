---
title: env
description: The keys in the env file, by what they unlock.
---

Always on. Reads the env file (`envFile`, `.env` by default) merged with the process environment.

```ts title="stackowl.config.ts"
env: {
  required: ['DATABASE_URL', 'AUTH_SECRET'],
  groups: {
    'Sign-in': ['GOOGLE_CLIENT_ID'],
    Email: ['RESEND_API_KEY'],
    Payments: ['STRIPE_SECRET_KEY'],
  },
  example: '.env.example',
},
```

- **`required`**: nothing works without them. A missing one is a problem (`✖`).
- **`groups`**: keys by the feature they unlock. A missing key only blocks its feature, so it's a note (`!`). The report says which feature: `! Payments: STRIPE_SECRET_KEY not set`.
- **`example`**: the keys in this file that have no value and aren't in a group are listed, so a new key added to `.env.example` doesn't go unnoticed. Set it to `false` to turn this off.

When the env file doesn't exist, the report says how to make it: `cp .env.example .env`.
