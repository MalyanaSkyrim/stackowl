---
title: github
description: Repository variables, secrets, environment secrets, labels and branches.
---

On when the config has a `github` section. Works on the repository of the config's folder, through `gh`.

```ts title="stackowl.config.ts"
github: {
  variables: {
    API_URL_STAGING: { why: 'the API staging builds call' },
    WEB_URL_PRODUCTION: { why: 'links in emails', fallback: 'https://www.example.com' },
  },
  secrets: ['SENTRY_AUTH_TOKEN'],
  environmentSecrets: {
    production: ['DEPLOY_KEY', 'APP_STORE_CONNECT_PRIVATE_KEY'],
  },
  labels: ['migration', 'skip-staging-deploy'],
  branches: ['production'],
},
```

| Field                | `doctor` checks                         | `setup --apply` does            |
| -------------------- | --------------------------------------- | ------------------------------- |
| `variables`          | Each exists and matches the env file    | Sets missing or different ones  |
| `secrets`            | Each repository secret exists           | Nothing (values stay with you)  |
| `environmentSecrets` | Each environment holds its secrets      | Nothing                         |
| `labels`             | Each label exists                       | Creates missing ones            |
| `branches`           | Each branch exists                      | Nothing: it says how to push it |

## Before it runs

1. Install the GitHub CLI: [cli.github.com](https://cli.github.com).
2. Log in: `gh auth login`.
3. The config's folder must have a GitHub remote. Without one, GitHub is skipped with a note.

In GitHub Actions, give `gh` a token with `GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}`. Reading environment secrets needs a token with admin access to the repository.
